# CSV 批量导入指南

> 本文档是 CSV/Excel 批量导入功能的**唯一事实来源**：模板格式、列约定与类型映射。
> 配套生成模板：应用内「数据管理 → 下载模板」（生成 `import_template.xlsx`，含资产/负债两个工作表）。

## 支持的文件

| 格式 | 说明 |
|---|---|
| `.xlsx` | 读取**第一个工作表**；不依赖表头行号，自动识别包含「名称」的列所在行 |
| `.csv` | 自动嗅探分隔符（`,` / `;` / `\t`）；推荐 UTF-8 编码（含 BOM 亦可） |

编码、行数、逐行错误都会在导入预览/结果报告中指出；**已解析但字段缺失的「跳过行」也会在预览中列出**。

## 统一约定

- **币种**：文件不包含币种列，按「当前统一币种」导入（默认 CNY）。
- **金额列**：不带货币符号的**纯数字**（元），支持 `3200000`、`3,200,000`、`1.5万` 等输入形式，最终以元存储。
- **日期列**：`2024-01-31` 或 `2024/1/31`。
- 单元格内容首尾空白自动去除；列标题支持别名（见下表）。

## 工作表一：资产

第一列必须是「类型」，否则整行跳过。

### 必需列

| 列标题 | 说明 |
|---|---|
| 类型 | 资产类型（中文/内置/自定义均可，见下） |
| 名称 | 资产名称 |
| 金额 | 当前价值（元） |

> 提示：股票/基金导入填**代码、买入价、数量**时，「金额」应为**当前市值**（= 买入价 × 数量 更佳，二者不一致时以表单校验口径为准）。

| 备注（/ 说明） | 备注 | 全部 |
| 买入价（/ 成本价 / 买入单价 / 成本单价） | 买入单价 | 股票、基金 |
| 现价（/ 当前价 / 最新价 / 现单价） | 当前单价 | 股票、基金 |
| 代码（/ 证券代码 / 基金代码 / 代码/编号） | 证券/基金代码 | 股票、基金 |
| 交易所 | 交易所/平台 | 股票 |
| 数量（/ 份额 / 持有份额 / 股数） | 持有数量 | 股票、基金 |
| 地址（/ 房产地址 / 房屋地址） | 房产地址 | 房产 |
| 面积（/ 建筑面积） | 建筑面积（㎡） | 房产 |
| 套内面积（/ 使用面积） | 使用面积（㎡） | 房产 |

### 「类型」列支持的值

| 填法 | 例子 |
|---|---|
| 内置类型中文名 | `房产`、`存款`、`股票`、`基金`、`保单` |
| 内置类型代码 | `property`、`deposit`、`stock`、`fund`、`insurance` |
| 自定义资产类型 | 填自定义类型的**名称**（如 `黄金`），或带 `custom_` 前缀的 ID |
| 对应负债类型 | 填 `房贷` 的行会**自动导入到「负债」工作表**（见下） |

## 行错误与跳过

每一行独立校验；**只跳过错误行，不中断整体导入**。常见跳过原因：

- 类型无法识别（未匹配中文名/代码/自定义类型/对应负债类型）
- 缺少必需字段（类型/名称/金额）
- 金额不是合法数字
- 自定义类型只存在于「资产」工作表时，指向负债的填写会失败

预览界面会逐行列出「将导入（资产/负债）」与「跳过 + 原因」；确认后仅导入合法行。
