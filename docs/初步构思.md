四、技术栈（直接抄作业）
| 层级 | 选型 | 理由 |
|---|---|---|
| 跨端 core | Rust + SQLite + SQLCipher | 单代码，手机/桌面/未来 WebAssembly 复用 |
| 移动端 | Rust → UniFFI → Swift/Kotlin | 0 成本双端，包体积 < 30 MB |

| 构建 | GitHub Actions | 自动出 apk/ipa/msi/dmg |
| 分发 | F-Droid、GitHub Release、酷安、TestFlight | 0 上架费，开源即合规 |

1. **完全免费 + 捐赠**（GitHub Sponsor、爱发电）

3. **增值服务**（可选，不碰数据）

七、合规&隐私（一次性过审）
- 国内：  
  - 应用商店要求《隐私政策》→ 直接写“本应用不收集任何个人信息”，附空白清单，已通过酷安实测。  
  - 工信部 164 号：开源软件无后端，可免备案。  
- 海外：  
  - F-Droid 自动扫描无追踪器，零障碍上架。  
  - Google Play 填“Data safety”全部选 No，附 GitHub 源码即可。
